# Python - Hello, World

This directory contains introductory Python programming tasks for the ALU Higher Level Programming project.

## Files

* `0-run`: A Bash script that runs a Python file whose name is stored in the `PYFILE` environment variable.

## Usage

Set the environment variable to the name of your Python file:

```bash
export PYFILE=main.py
```

Run the shell script:

```bash
./0-run
```

The script executes the specified Python file using Python 3.
