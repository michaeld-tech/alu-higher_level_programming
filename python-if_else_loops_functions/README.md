# Python - if/else, loops, and functions

This project introduces the basics of Python programming, including conditional statements, loops, and functions.

## Task 0: Positive anything is better than negative nothing

The program assigns a random signed number to the variable `number` and prints whether the number is positive, zero, or negative.

### Output examples

- Positive number: `7 is positive`
- Zero: `0 is zero`
- Negative number: `-4 is negative`

### How to run

Make the Python file executable:

    chmod +x 0-positive_or_negative.py

Run the program:

    ./0-positive_or_negative.py

The output may change each time because the program generates a random number.

## Requirements

- Python 3
