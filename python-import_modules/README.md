# Python Import Modules

This directory contains Python programs demonstrating how to import and use functions from other Python files.

## Task 0: Import a Simple Function

The `0-add.py` program imports the `add` function from `add_0.py`, assigns the values 1 and 2 to variables `a` and `b`, and prints the addition in the format `1 + 2 = 3`.

## Execution

Run the program using:

```bash
./0-add.py
